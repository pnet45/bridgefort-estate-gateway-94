# Bridgefort Homes UI and Content Standards

## Professional presentation
- Do not use emojis in any Bridgefort Homes website, mobile app, admin console, email, notification, marketing content, or generated copy.
- Remove existing emojis when editing existing content. Do not introduce new emojis in future work.
- Use the project's Lucide/vector icon components for interface icons. Icons must have clear meaning, consistent sizing, accessible labels where needed, and theme-aware colors.
- For text-only content, use clear headings, normal punctuation, and professional bullet lists instead of emoji decoration.
- Preserve meaningful content, business details, accessibility, and existing functionality when removing decorative symbols.
- Keep the Bridgefort Homes Development Ltd brand voice professional, trustworthy, client-focused, and easy to understand.
- Use the current brand slogan, "Bringing your dream home"; do not reintroduce the discontinued "Rebuilding the future" slogan.
